# Shared pipeline helpers

These modules regenerate graph features and expose the history/partition helpers used by the root `run_models.py`. They originated in the Trial120 reproduction package. The selected 1019-6 uses the soft-window worker and five seeds through the new root entry point, while 0929-1 uses the binary historical-risk stack. Do not use the older Trial120 validation values as measurements of the selected soft-window ensemble.
